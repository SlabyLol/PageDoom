# PageDoom

Doom WASM runner for GitHub Pages with mobile on-screen buttons and full PC keyboard support.

**Live demo:** https://slabylol.github.io/PageDoom/

## Features
- Works on desktop (keyboard + mouse focus)
- Mobile touch controls (D-pad, Fire, Use, Run, Strafe, Menu)
- Single file, ready for GitHub Pages
- Uses open-source wasm-doom package

## Controls

**PC**
- Arrow keys / WASD – move
- Ctrl – Fire
- Space – Use / Open doors
- Shift – Run
- Alt – Strafe
- Esc – Menu

**Mobile**
- On-screen buttons appear automatically

## Deploy
This repo is already set up for GitHub Pages.  
Just enable Pages in Settings → Pages → Deploy from branch `main`.
